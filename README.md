# Portfolio website v2

Persoonlijke portfolio site (Vite + React + TypeScript + Tailwind CSS + Supabase) met een beveiligde
`/admin`-omgeving om projecten te beheren zonder code aan te passen.

> Project in opbouw — volledige installatie- en gebruiksinstructies volgen in de laatste fase.

## Snel starten

```bash
npm install
cp .env.example .env   # vul VITE_SUPABASE_URL en VITE_SUPABASE_ANON_KEY in
npm run dev
```
